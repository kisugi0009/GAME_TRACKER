# Game Tracker

一款專為手遊玩家設計的任務與資源管理工具，以純 HTML 單檔實作，無需安裝、無需帳號，開啟即用。

---

## 功能總覽

### 多遊戲管理
- 可新增多款遊戲，各自獨立追蹤進度
- 支援拖曳排序，自由調整遊戲顯示順序
- 首頁總覽卡片顯示各遊戲待完成任務數與下次重置時間

### 任務系統

**日常任務（Daily）**
- 設定每日固定重置時間（例如每天 05:00）
- 到達重置時間後自動恢復為未完成狀態
- 打勾後顯示距離下次重置的剩餘時間

**週期任務（Cycle）**
- 支援自訂重置週期（天數）
- 提供快速選擇（7 天）或手動輸入天數
- 也可透過選擇「開始 / 結束日期區間」自動換算天數
- 適合週常、雙週、活動期間限定任務

任務列表支援拖曳排序，可依個人習慣整理順序。

### 卡池追蹤（Gacha）
各遊戲可獨立開啟卡池模組，功能包含：
- 新增多個卡池，設定名稱與活動起訖日期
- **大保底計數器**：可設定大保底抽數上限，直接在卡片上編輯目前已抽數，接近上限時以顏色警示（黃色 / 紅色）
- **小保底計數器**：支援有小保底（50/50）機制的卡池，同樣可直接編輯
- **保證狀態**：記錄是否已保證下一發必中限定，點擊切換
- **自訂打勾項目**：可自行定義卡池內要追蹤的項目（如限定角色、專武、情報、通行證等），逐一勾選

### 角色收藏冊（Roster）
各遊戲可獨立開啟角色收藏模組，功能包含：
- 新增角色，記錄稀有度、職業 / 標籤、備註
- 點擊角色卡片切換「已獲得 / 未獲得」狀態
- 依稀有度自動排序，高稀有度優先顯示
- **篩選功能**：全部 / 已獲得 / 未獲得 / 依標籤篩選
- **搜尋功能**：即時搜尋角色名稱或標籤
- 顯示獲得進度（已獲得 / 總數）
- 收合 / 展開面板，節省畫面空間
- **Excel 匯入**：支援 .xlsx / .xls / .csv，可自動對應欄位（名稱、稀有度、標籤、已獲得、備註），可下載範例檔參考格式

### 資料管理

**本地備份**
- 資料存放於瀏覽器 LocalStorage
- 支援匯出 JSON 備份檔至本機
- 支援從 JSON 備份檔還原資料

**雲端備份**
- 一鍵上傳資料至雲端，取得 10 碼備份代碼（格式：`GT-XXXXXXXXXX`）
- 在任何裝置輸入代碼即可還原資料
- 備份於 **14 天後自動過期刪除**，請妥善保存代碼並定期重新備份

### 主題樣式
提供四種介面主題，可在設定中切換：

| 主題 | 風格 |
|------|------|
| Dark | 深色系，預設主題 |
| Tech | 科技藍，淺色系 |
| Girly | 粉色系，淺色系 |
| Fresh | 清新綠，淺色系 |

## 使用方式

### 開始使用
1. 用瀏覽器開啟 `index.html`（或已部署的網址）
2. 點擊右上角「**新增遊戲**」
3. 輸入遊戲名稱、設定每日重置時間，選擇要啟用的功能模組
4. 進入遊戲頁面後，點擊「**+ 日常任務**」或「**+ 週期任務**」開始新增

### 任務操作
- **打勾**：點擊任務左側方框標記完成
- **再點一次**：取消完成狀態
- **拖曳**：按住任務左側的 `⠿` 圖示進行排序
- **編輯**：滑鼠移到任務上會出現「編輯」按鈕

### 卡池操作
- 在遊戲設定中開啟「卡池追蹤」模組
- 點擊「**+ 卡池**」新增卡池，設定保底數值
- 直接點擊保底數字欄位編輯目前已抽數

### 角色收藏操作
- 在遊戲設定中開啟「角色收藏冊」模組
- 手動新增角色，或透過「**↑ 匯入 Excel**」批次匯入
- 點擊角色卡片切換獲得狀態

### 備份建議
> 資料存放於瀏覽器快取，清除瀏覽器資料、更換裝置或瀏覽器時資料將會消失。
> 建議定期使用「匯出 JSON」或「雲端備份」功能保存資料。

## 技術說明

- 純 HTML + CSS + JavaScript 單檔實作，無任何框架依賴
- 字型：Space Mono（等寬）、Noto Sans TC（中文）
- Excel 解析：[SheetJS（xlsx）](https://sheetjs.com/)
- 資料存放：瀏覽器 LocalStorage（鍵名：`game-tracker-v1`）
- 雲端備份：透過 Cloudflare Workers 提供的外部 API

---

## 注意事項

- 清除瀏覽器快取、使用無痕模式，或更換裝置 / 瀏覽器時，本地資料將無法取得，請務必在操作前先備份
- 雲端備份代碼有效期限為 14 天，請記下代碼並定期重新上傳
- 本工具為純前端工具，不會自動同步資料至任何伺服器（雲端備份功能除外，需手動操作）
